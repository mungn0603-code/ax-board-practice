# 확인 기록 — 실습 B

## 원문 확보
- 작업 환경 네트워크가 사이트를 막아 본인 브라우저로 받았다. 1페이지는 원문 전체를 옮겼고, 클라우드 파일의 SHA-256(fc2965ac…)이 브라우저 기록과 같다.
- 2·3페이지는 원문 전체를 옮기다 손상돼(CRC 오류) 버렸다. 브라우저에서 원문 해시·바이트를 기록하고 tr.team 행 값만 옮겼다.

## B5·B6 (runs/b04_threepages)
- 25+25+25=75행, 서로 다른 팀 이름 26개, 팀시즌 키 75개(중복 없음)
- 같은 팀 다른 시즌: Boston Bruins|1990(1p 1행), Boston Bruins|1991(1p 22행) → 서로 다른 기록으로 남김
- OT Losses는 75행 모두 빈칸이다. 뜻을 확인하지 못해 0으로 바꾸지 않았다.

## B8 결론
- 자료로 확인: Boston Bruins의 1990·1991·1992년 승수는 44·36·51이고, 1992년이 가장 많다. 1991년보다 15승 많다.
- 범위를 넘는 주장: 세 페이지 75행만으로 전체 역대 최고 팀이나 현재 순위는 말할 수 없다.

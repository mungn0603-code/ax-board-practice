# AX 아이디어 보드 PRD (가설 초안)

작성일: 2026-10-10(실습일) / 2026-10-22 작성 · 팀명: 개인 실습 · 작성자: 문규남
작성 방식: 작성자의 아이디어를 Claude로 템플릿화해 초안을 잡고, 직접 검토하며 구체화했다. 확인하지 않은 내용은 [가설]로 표시한다.

## Q1 사용자
- 제조 현장의 업무 담당자 중 AI 활용 아이디어를 모으는 사람 [가설]. 예: 설비 점검 담당자

## Q2 문제
- 업무 중 떠오른 AI 활용 아이디어가 메모·메신저에 흩어져 다시 찾기 어렵다 [가설]

## Q3 해법
- 제목·대상 업무·AI 아이디어 3칸으로 카드를 남기고, 한 화면에서 다시 찾게 한다

## Q4 기능 3개
1. 카드를 등록한다
2. 카드 목록을 보고 태그로 거른다
3. 필요 없는 카드를 확인 후 삭제한다

## Q5 화면
1. 보드 화면: 입력칸 + 카드 추가 버튼 + 카드 목록 (한 화면)

## Q6 성공 기준
- 카드를 등록하면 목록 맨 위에서 바로 찾을 수 있다
- 새로고침해도 카드와 개수가 유지된다

## 벤치마크 반영
- Trello처럼 등록 직후 카드 위치가 보여야 한다 → 새 카드를 목록 맨 위에 추가한다 (docs/benchmark.md)

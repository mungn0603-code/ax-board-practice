# 구조도 (5칸)

| Q4 기능 | Q5 화면 | 입력 | 처리 | 출력 |
|---|---|---|---|---|
| 카드 추가 (공통 예시) | 보드 | 제목·업무 | 새 카드 생성 | 목록 표시 |
| 카드 등록 | 보드 | 제목·대상 업무·AI 아이디어·태그 | 빈값 검사 → 카드 객체 생성 → localStorage 저장 | 목록 맨 위에 표시, 안내 문구 |
| 목록 조회 | 보드 | 태그 필터 선택 | 저장된 카드 읽기 → 태그로 거르기 | 현재 목록과 개수 |
| 카드 삭제 | 보드 | 삭제 → 확인/취소 | 확인 시 카드 제거 → 저장 | 카드 사라짐, 개수 감소 |

## 질문
- 저장 위치: 브라우저 localStorage(`ax-board-ideas`)뿐이다. 서버 DB·API는 없다.
- 권한: 로그인이 없어 누구나 자기 브라우저 데이터만 본다.
- 실패 조건: localStorage를 막은 브라우저(사생활 보호 모드 등)에서는 빈 목록으로 시작한다.

## 위험
- 브라우저를 바꾸거나 데이터를 지우면 카드가 사라진다.

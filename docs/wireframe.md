# 와이어프레임

## 기본 화면
```
AX 아이디어 보드                      아이디어 N개
[제목: 예) 설비 점검 기록 요약] [대상 업무] [AI 아이디어] [태그] [카드 추가]
안내 문구 줄 (추가/삭제/빈값 안내)
[태그 필터: 전체 ▾]
┌ 설비 점검 기록 요약 #생산 ─────────────── [삭제] ┐
│ 대상 업무: 생산 일지 확인                          │
│ 다음 확인 항목을 정리한다                          │
└──────────────────────────────────────────────┘
```

| 화면 | 입력·버튼 | 누른 뒤 결과 | 실패·미확인 조건 | 연결할 Q6 |
|---|---|---|---|---|
| 보드 | 3칸+태그, 카드 추가 | 맨 위에 카드, 개수 +1 | 빈칸이면 안내 후 추가 안 함 | 등록 후 바로 찾기 |
| 보드 | 삭제 → 확인 | 카드 삭제, 개수 −1 | — | 새로고침 후 유지 |
| 보드 | 삭제 → 취소 | 카드·개수 그대로 | — | 새로고침 후 유지 |

## 공통 AX 보드 목표 (P4 선택)
- B 선택: 3주차 Issue 실습에서 삭제 확인을 먼저 넣으므로, 제목 입력칸 안내 문구를 "예: 설비 점검 기록 요약"으로 바꾼다.

## 동료 점검 (짝이 없어 사용자 순서로 직접 읽음)
- 빠진 조건: 태그를 비워 두면 어떤 태그로 분류되는지 정하지 않았다 → 태그 없음으로 두고 필터 "전체"에서만 보이게 한다.

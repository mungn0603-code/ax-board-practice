# 벤치마크 — 같은 과업: 아이디어 카드 등록 후 다시 찾기

확인일: 2026-10-22 (공식 문서)
- Trello: https://support.atlassian.com/trello/docs/adding-cards/
- GitHub Projects: https://docs.github.com/en/issues/planning-and-tracking-with-projects

| 도구 | 같은 과업 | 입력 | 결과 | 막히는 점 | 우리 앱에 줄 결정 |
|---|---|---|---|---|---|
| Trello | 카드 등록 후 다시 찾기 | 리스트 아래 Add a card → 카드 이름만 입력 → Enter | 리스트 맨 아래에 카드 추가(위·중간 추가는 별도 메뉴) | 이름만 입력해 대상 업무 같은 맥락이 빠진다 | 등록 직후 위치가 보이도록 새 카드를 맨 위에 둔다 |
| GitHub Projects | 아이디어 항목 등록 후 다시 찾기 | Issue, PR, 초안(draft) 아이디어를 항목으로 추가 | 표·보드·로드맵 보기, 필터·정렬·그룹, 사용자 정의 필드 | 항목 추가 단계는 하위 문서에 있어 이번에 확인하지 않았다 | 필터 개념을 태그 필터로 가져온다 |
